# Restring

A collection of essential developer tools in one place. Restring is a web-based utility belt that helps you with common tasks like encoding/decoding data, formatting JSON, inspecting JWTs, and much more.

## Overview

Restring is built with SvelteKit and TailwindCSS, providing a fast, modern, and easy-to-use interface for a variety of development tasks. Whether you need to quickly convert a string to Base64, beautify a JSON object, or decode a JSON Web Token, Restring has you covered.

## Tools / Features

- **Base64:** Encode and decode strings to and from Base64.
- **JSON:** Format, validate, and inspect JSON objects.
- **JWT:** Decode and inspect JSON Web Tokens.
- **URL:** Encode and decode URL components.
- **Color:** Convert between different color formats (Hex, RGB, HSL).
- **DateTime:** Convert and manipulate dates and times.
- And more to come!

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/your_username/restring.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Start the development server
   ```sh
   npm run dev
   ```

## Building for Production

To create a production version of the app:

```sh
npm run build
```

You can preview the production build with `npm run preview`.
